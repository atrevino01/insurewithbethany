# Bethany D. Insurance Guidance

Static website files for the Bethany D. insurance site concept.

## Pages

- `index.html` — homepage
- `personal-insurance.html` — personal coverage information
- `business-insurance.html` — business coverage information
- `about.html` — about Bethany
- `contact.html` — email contact form and contact details

## Publish

Upload the contents of this folder to the root of a GitHub repository connected to Cloudflare Pages. Keep the `assets` folder beside the HTML files. This site has no build step; Cloudflare Pages can serve the static files directly.

Before publishing, replace the sample phone number on the Contact page with Bethany’s correct number. Confirm the email address and update any coverage descriptions to match the carriers, states, and products she is licensed to offer.
